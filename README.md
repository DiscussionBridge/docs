# DiscussionBridge Documentation

Learn how to add Discourse discussions to your site, connect a publishing
platform, and choose what can publish. [Read the documentation](https://docs.discussionbridge.dev/).

- [Set up DiscussionBridge](https://docs.discussionbridge.dev/alpha-operator-guide/)
- [Choose your platform](https://docs.discussionbridge.dev/platform-profiles/)
- [Check versions and live status](https://docs.discussionbridge.dev/versions-and-live-status/)

To contribute a correction, edit the source in [`docs/`](docs/). Run
`npm run refresh-metadata` and `npm run build` to update the page and
check the site locally.
